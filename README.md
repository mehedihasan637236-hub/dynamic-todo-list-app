# ✨ Dynamic To-Do List App

## 📋 প্রজেক্ট পরিচিতি (About The Project)

এই প্রকল্পটি একটি সম্পূর্ণরূপে কার্যকরী ওয়েব অ্যাপ্লিকেশন, যা ব্যবহারকারীদের প্রতিদিনের কাজগুলি (tasks) দক্ষতার সাথে পরিচালনা করতে সাহায্য করে। এই অ্যাপটি অত্যাধুনিক ইউজার ইন্টারফেস (UI) এবং লোকাল স্টোরেজ (Local Storage) ইন্টিগ্রেশনের মাধ্যমে টাস্ক ডেটা স্থায়ীভাবে সংরক্ষণ করার সুবিধা প্রদান করে।

## 🛠 প্রযুক্তি (Tech Stack)

এই প্রকল্পটি নিম্নলিখিত প্রযুক্তিগুলো ব্যবহার করে তৈরি করা হয়েছে:

* **HTML5:** কাঠামোর জন্য।
* **CSS3:** স্টাইলিং এবং রেসপনসিভ ডিজাইনের জন্য।
* **JavaScript (ES6+):** মূল কার্যকারিতা (Logic) এবং ডাইনামিক ইন্টারফেসের জন্য।
* **Local Storage API:** টাস্ক ডেটা ব্রাউজারে স্থায়ীভাবে সংরক্ষণের জন্য।

---

## 💡 প্রধান বৈশিষ্ট্যসমূহ (Key Features)

* **ডাইনামিক টাস্ক ম্যানেজমেন্ট:** সহজেই নতুন টাস্ক যোগ করা, সম্পাদনা করা এবং মুছে ফেলা যায়।
* **লোকাল স্টোরেজ ইন্টিগ্রেশন:** অ্যাপ বন্ধ করার পরেও টাস্কগুলি সুরক্ষিত থাকে।
* **ক্লিন ইউজার ইন্টারফেস:** ব্যবহারকারী-বান্ধব এবং আধুনিক ডিজাইন।
* **কমপ্লিশন ট্র্যাকিং:** টাস্কগুলি সম্পূর্ণ হলে সেগুলিকে চিহ্নিত করার সুবিধা।

## 🚀 সেটআপ ও ব্যবহার (Installation and Setup)

1.  **Repository Clone করুন:**
